# Background VFX Particle Assets

Place custom particle images or animated sprite sheets here. When an image exists in this folder, MindSpace will automatically load and render it for that particle effect!

### Supported Files:
- `sakura.png` / `sakura.gif` - Cherry blossom petal
- `fireflies.png` / `fireflies.gif` - Glowing firefly
- `hearts.png` / `hearts.gif` - Floating heart
- `snow.png` / `snow.gif` - Crystalline snowflake
- `cyber.png` / `cyber.gif` - Matrix / cyber rain streak
- `cosmic.png` / `cosmic.gif` - 4-point twinkling diamond star

Format: Transparent PNG or GIF (recommended size: 32x32 to 64x64 transparent background).
