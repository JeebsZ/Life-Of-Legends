# Study (flashcards + exam simulator) - 2026-11-05

More -> Plan & focus -> Study (pinnable to the center slot like any More tile).

- Core: `core/study.py` (parser, generators, StudyRun, Leitner SRS, XP); `TextRecognizer` protocol + manual fallback; `ui/ocr.py` `recognizer_for(page)` is the single OCR hook.
- Save (schema 5, additive): `decks` (cards, category, daily_limit, exam_date, quest_id), `study_sessions`, `study_settings.daily_limit`. Old saves load with defaults (tests). Decks are in JSON backup, summary and CSV (`study_cards.csv`, `study_sessions.csv`).
- Notes parser formats: `term - def` (also en/em dash), `term: def`, `term = def`, TAB/spreadsheet, `Q: .. A: ..` (inline or two lines), bullets/numbered lists, `#`/`**bold**` headings with text below, `Term:` then text below, plain short line + longer line (low confidence). Drafts carry high/medium/low confidence and a duplicate flag; the player ticks/edits before saving.
- Questions: multiple choice (4 options, similar-length distractors, falls back to true/false then type), true/false, fill-in-the-blank (longest specific non-stopword), type answer, flip card. Typo tolerance by edit distance; case/accents/articles ignored.
- SRS: Leitner boxes 0-5 (0,1,2,4,8,16 days). Quiz right = +1 box, miss = box 0. Flip ratings: Again = box 0, Hard = stay (>=1) due tomorrow, Good = +1, Easy = +2. States: New / Learning / Reviewing / Confident.
- XP: 1 XP per card answered, max 15 per session, x1 / x0.5 / x0.25 / 0 for the 1st..4th session on the same deck per day, 45 per day total; 2 coins on a deck's first rewarded session (6/day). Sessions under 3 cards give none. A linked quest completes (normal quest reward) when a session finishes.
- Modes: Exam (types, count, timer), Learn (misses repeat), Flip cards, Review due (daily limit applies), Weak cards.
- Scan notes: phone camera/picker -> `LumenOcr` extension (ML Kit Latin, see extensions/flet_lumen_ocr/README.md) -> same parser -> draft review. Web/desktop: paste or type.
