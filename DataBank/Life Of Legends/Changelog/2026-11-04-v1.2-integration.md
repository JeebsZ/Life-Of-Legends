# 2026-11-04 - v1.2 integration (More tab, editing, templates, chains, focus, calendar, backup, settings, effects + SFX)

- Bottom bar: Today · Quests · Bills · Rewards · **More**. More is a tile grid (You / Plan & focus / Data & app) opening sub-screens on an in-app stack with a back arrow and slide transitions: Profile, Skills (skill-link trees), Achievements (locked, coming soon), Lumen Report, Calendar, Focus Timer, Templates, Logbook, Backup & Export, Settings.
- Edit everywhere: quest dots menu (Edit, Save as template, Focus on this, Remove); custom XP/coin sliders show the difficulty cap. Bills: tap = edit (name, amount, next due, repeat), Archive vs Delete with confirms, Archived section. Rewards: dots menu (Edit, Archive, Remove), Archived section. Side quests: dots = order toggle, target date, pause/resume, move up/down, rename, skip/unskip, set aside.
- Make your own side quest: "Generate steps with Lumen" (LumenThinking, then editable steps), ordered toggle, target date. Today shows "Next steps".
- Effects: overall level-up = MilestoneSeal; skill acquired / rank up = NoticeEmblem; Path level-up = old banner; one big effect per action, the rest become Lumen notices. Theme bought / side quest started = IdentifyReveal. Ask Lumen, generate, and Lumen Report = LumenThinking.
- SFX wired with `sfx.init`; Settings has SFX on/off + volume and Reduce effects. New profile fields: `sfx_on`, `sfx_volume`, `reduce_effects`. They are defaults only, so the schema did not change.
- Known: on Flutter web the focus timer's clock rings stay still, because the rotating spiral crashed skwasm. Native builds still rotate.
